# AWS RoboMaker warehouse assets (converted)

Converted OBJ/PNG copies for MuJoCo. **Source of truth** is the git submodule:

`third_party/aws-robomaker-small-warehouse-world`

```bash
git submodule update --init third_party/aws-robomaker-small-warehouse-world
python3 scripts/import_aws_warehouse_assets.py
```

See `IMPORTED_ASSETS.md` for the current inventory (regenerated by the import
script). License: MIT-0 (Amazon).

Manipulator place receptacles are analytic open bins in the pick-place MJCF
templates (not warehouse meshes). `meshes/bucket.obj` is a multi-compartment
mop cart and is unsuitable as a single drop-in container.
